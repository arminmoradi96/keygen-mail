# Beiträge

Fehlerberichte und Pull Requests sind willkommen, sobald das Repository
öffentlich und eine Lizenz festgelegt ist. Bitte keine Passwörter, echten
Installations-IDs, Kundendaten oder privaten Serveradressen mitsenden.
Änderungen möglichst mit Tests und einer kurzen Beschreibung einreichen.
