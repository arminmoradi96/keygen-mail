# Sicherheit / Security

Bitte niemals SMTP-/POP3-Passwörter, produktive Konfigurationsdateien,
E-Mail-Inhalte, private Links oder Server-Logs in Issues oder Commits posten.
Für Sicherheitsmeldungen zunächst einen privaten Kontaktkanal des Repository-Betreibers nutzen.

**Hinweise:** Diese Mailer bearbeiten eingehende E-Mails und verwenden teils
externe Programme. Nur vertrauenswürdige Absender zulassen, Mailbox-Zugriff
begrenzen und auf einem isolierten System testen. Backups per E-Mail können
vertrauliche Inhalte enthalten; geeignete Verschlüsselung und Größenlimits
prüfen. TLS deaktivieren ist unsicher und nur in kontrollierten Testumgebungen
vertretbar.
